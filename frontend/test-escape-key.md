# ทดสอบ Escape Key ในการยกเลิกการวาด

## การทดสอบที่ควรผ่าน:

### 1. ทดสอบ Polyline
1. คลิกปุ่ม "วาด Polyline" 
2. คลิกหลายจุดบนผัง (เช่น 2-3 จุด)
3. กด Esc
4. **ผลลัพธ์ที่คาดหวัง**: กลับไปโหมด "select" และจุดที่วาดไว้หายไป

### 2. ทดสอบ Rectangle  
1. คลิกปุ่ม "วาด Rectangle"
2. คลิกจุดแรกบนผัง
3. เลื่อนเมาส์ (จะเห็น preview rectangle)
4. กด Esc
5. **ผลลัพธ์ที่คาดหวัง**: กลับไปโหมด "select" และ rectangle preview หายไป

### 3. ทดสอบ Rectangle (ก่อนคลิกจุดแรก)
1. คลิกปุ่ม "วาด Rectangle" 
2. กด Esc ทันที (ก่อนคลิกจุดใดๆ)
3. **ผลลัพธ์ที่คาดหวัง**: กลับไปโหมด "select"

### 4. ทดสอบในโหมด Select
1. อยู่ในโหมด "select"
2. กด Esc
3. **ผลลัพธ์ที่คาดหวัง**: ไม่มีผลกระทบใดๆ (ยังคงอยู่ในโหมด select)

## ข้อความแนะนำที่ควรแสดง:

- **Polyline (ยังไม่มีจุด)**: "เลือกจุดบนผังเพื่อเริ่มวาด Polyline (กด Esc เพื่อยกเลิก)"
- **Polyline (มีจุดแล้ว)**: "คลิกเพื่อเพิ่มจุด, ดับเบิลคลิกเพื่อจบ, คลิกขวาเพื่อย้อนกลับ, เข้าใกล้จุดแรกเพื่อปิดพื้นที่ (กด Esc เพื่อยกเลิก)"
- **Rectangle (ยังไม่คลิกจุดแรก)**: "คลิกมุมแรกของสี่เหลี่ยมบนผัง (กด Esc เพื่อยกเลิก)"  
- **Rectangle (คลิกจุดแรกแล้ว)**: "เลื่อนเมาส์และคลิกมุมตรงข้ามเพื่อสร้างสี่เหลี่ยม หรือคลิกขวาเพื่อเริ่มใหม่ (กด Esc เพื่อยกเลิก)"
